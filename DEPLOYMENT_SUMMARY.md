## 🎯 Deploy in 3 Steps

### Step 1: Run Setup Script
```bash
cd /Users/nykb/Downloads/alphapath_backend
./deploy-setup.sh
```

### Step 2: Push to GitHub
```bash
# Create repo at: https://github.com/new (name: alphapath-backend)

git remote add origin https://github.com/YOUR_USERNAME/alphapath-backend.git
git branch -M main
git push -u origin main
```

### Step 3: Deploy on Render
1. Go to https://render.com/dashboard
2. Click **"New +"** → **"Blueprint"**
3. Select your `alphapath-backend` repository
4. Click **"Apply"**
5. Wait ~5-10 minutes

**Your API will be live at**: `https://alphapath-api.onrender.com`

## 🔐 Security Recommendations

Before going live with real users:

1. **Update JWT Secrets**
   ```bash
   # Generate secure secrets
   openssl rand -hex 32
   ```

2. **Restrict CORS**
   ```bash
   CORS_ORIGIN=https://yourdomain.com,http://localhost:3000
   ```

3. **Set Up Monitoring**
   - Enable Sentry for error tracking
   - Use LogRocket for user sessions
   - Monitor logs in Render dashboard

4. **Custom Domain**
   - Add your domain in Render settings
   - Update DNS records

## 🆘 Need Help?

### Common Issues

**Build Failed?**
- Check Render logs for errors
- Verify all dependencies in package.json
- Test build locally: `npm run build`

**Database Connection Error?**
- Ensure DATABASE_URL is set
- Check database is in same region
- Verify database is not paused

**API Not Responding?**
- Service may be spinning up (wait 60s)
- Check logs in Render dashboard
- Verify PORT is set to 10000
